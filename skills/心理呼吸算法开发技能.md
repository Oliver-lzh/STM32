# RadarBaseboardMCU7 心理呼吸算法开发技能

## 1. 文档目标

参考 TI `vitalSigns_16xx_dss` demo 中的呼吸率、心率处理思路，分阶段移植到 RadarBaseboardMCU7 固件。

## 3. TI 算法核心

### 3.1 PCA I/Q 轨迹校正 (dss_pca_vitalsigns.c)

**PCA 原理:**
- 128 点 I/Q 环形缓冲区
- 计算协方差矩阵 `C = [C11 C12; C12 C22]`
- 求主轴特征向量，旋转 I/Q 轨迹
- 保持轴方向连续性避免相位翻转

```c
// 缓冲区
static float I_buffer[128];
static float Q_buffer[128];

// 主轴更新
lambda1 = 0.5f * (trace + sqrt(disc));
v1 = C12; v2 = lambda1 - C11;

// 旋转
*I_out = I_in * pca_v1 + Q_in * pca_v2;
*Q_out = -I_in * pca_v2 + Q_in * pca_v1;
```

### 3.2 呼吸信号处理 (BreathSignal_process)

```c
// 高通滤波 (α=0.995)
hp_out = 0.995f * (hp_prev + unwrapped_phase - prev_in);
prev_in = unwrapped_phase;
hp_prev_out = hp_out;

// 低通滤波 (α=0.08)
lp_out = 0.08f * hp_out + 0.92f * lp_prev;
return lp_out;
```

### 3.3 心跳信号处理 (HeartSignal_process)

```c
// 趋势跟踪 (α=0.01)
trend = 0.99f * trend + 0.01f * phase;
detrend = phase - trend;

// 呼吸信号去除
breath_remove = 0.98f * breath_remove + 0.02f * detrend;
detrend = detrend - breath_remove;

// 差分限幅
diff = detrend - prev_detrend;
diff = clip(diff, ±0.05);

// 高通 + 低通 + 平滑
hp = 0.92f * (hp_prev + diff - diff_prev_in);
lp = 0.22f * hp + 0.78f * lp_prev;
return 3.0f * smooth;
```

### 3.4 相位展开 (unwrap)

```c
diffPhase = phase - phasePrev;
if (diffPhase > PI)      diffPhase -= TWO_PI;
else if (diffPhase < -PI) diffPhase += TWO_PI;
if (fabs(diffPhase) > 1.0f) diffPhase = 0.0f;
*phaseCum += diffPhase;
return *phaseCum;
```

### 3.5 处理链路

```
range bin I/Q (慢时间序列)
  → atan2(Q,I) 得到相位
  → unwrap 相位展开
  → PCA_VitalSigns_process (I/Q轨迹校正)
  → BreathSignal_process → 呼吸波形
  → HeartSignal_process → 心跳波形
  → FFT → 频谱
  → find_Peaks → BPM 估计
```

## 4. 实现阶段

### 阶段 A: AppRangeFft - 单 chirp Range FFT

**目标:** 在 Cortex-M7 上验证 Range FFT，找到目标 range bin

**实现:**
- 使用 CMSIS-DSP `arm_rfft_fast_f32()`
- 输入：Packed12 数据 (12bit 压缩)
- 输出：64 点复数 FFT 的幅值
- 找幅值最大 bin 作为目标

**文件:**
- `AppRangeFft.c/.h`

### 阶段 B: AppVitalSigns - 生命体征核心算法

**目标:** 实现相位展开 + PCA + 呼吸/心跳滤波

**实现:**
- 环形缓冲区保存目标 range bin 的 I/Q 历史 (128 点)
- `unwrap()` 相位展开
- `PCA_VitalSigns_process()` I/Q 轨迹校正
- `BreathSignal_process()` 呼吸带通滤波
- `HeartSignal_process()` 心跳带通滤波

**文件:**
- `AppVitalSigns.c/.h`

### 阶段 C: AppVitalSignsOutput - 输出集成

**目标:** DEBUG_TEXT 模式输出呼吸/心跳 BPM

**输出格式:**
```
vital,breath=<breath_bpm>,heart=<heart_bpm>,quality=<conf>
```

## 6. 各阶段验证方法

### 阶段 A: Range FFT ✅ 容易验证

**验证方法:** 人体在不同距离测试，观察峰值 bin 变化

```
你站在雷达前 0.5m 处 → fft,bin=5,mag=1234
你站在雷达前 1.0m 处 → fft,bin=10,mag=1234
你站在雷达前 2.0m 处 → fft,bin=20,mag=1234
```

峰值 bin 应该随距离**线性变化**。如果 bin 不随距离变化说明 FFT 没有工作。

### 阶段 B: 相位展开 (unwrap)

**验证方法:** 输出原始相位 vs 展开相位，检测 ±2π 跳变修正

```
phase,raw=3.14,unwraped=3.14
phase,raw=-3.10,unwraped=6.28  ← 检测到 -π → +π 跳变，自动修正
phase,raw=-3.05,unwraped=6.33
```

正常呼吸时展开相位应该**连续无突变**，如果有±2π的跳跃说明 unwrap 有 bug。

### 阶段 B: PCA 校正

**验证方法:** 输出校正前后的 I/Q 幅值，对比稳定性

```
pca,before_i=0.8,before_q=0.3,after_i=0.85,after_q=0.1
pca,before_i=0.7,before_q=0.4,after_i=0.75,after_q=0.15
```

PCA 校正后 I/Q 轨迹应该更稳定（相位噪声小），如果校正后反而更差说明 PCA 有问题。

### 阶段 B: 呼吸信号

**验证方法:** 故意憋气，观察信号变化

```
breath,in=0.05,out=0.12  ← 正常呼气
breath,in=0.02,out=0.08  ← 憋气中，信号应该趋于平缓
breath,in=0.04,out=0.11  ← 恢复呼吸
```

憋气时呼吸波形应该**趋于平坦**，恢复呼吸后重新出现周期波形。

### 阶段 B: 心跳信号

**验证方法:** 静息测一次，起立快呼吸测一次

```
heart,in=0.01,out=0.03   ← 静息，心跳信号微弱
heart,in=0.02,out=0.06   ← 运动后，心跳信号增强
```

心跳信号幅值应该随**心率增加而增强**，但呼吸干扰也会变大。

### 阶段 C: BPM 输出

**验证方法:** 用秒表对照

```
vital,breath=15,heart=72,quality=0.8   ← 手动数呼吸次数对照
vital,breath=14,heart=75,quality=0.7   ← 误差应该在 ±3 BPM 内
```

## 8. 数据格式解析

### Packed12 格式

每个 sample 占 12 bits，存储时压缩到 1.5 bytes：
- 低 8 bits: `data[i] & 0xFF`
- 高 4 bits: `data[i] >> 8` 放在下一个 byte 的低 4 bits

### 帧数据布局 (36864 bytes/frame)

```
[Chirp0 RX0: 64×1.5=96 bytes]
[Chirp0 RX1: 64×1.5=96 bytes]
[Chirp0 RX2: 64×1.5=96 bytes]
[Chirp1 RX0: 64×1.5=96 bytes]
...
[Chirp127 RX2: 64×1.5=96 bytes]
-----------------------
总计: 128×3×96 = 36,864 bytes
```

## 10. 注意事项

1. **不要照搬 TI 的 EDMA/DSS 架构**，英飞凌 MCU 没有独立 DSP
2. **第一版只缓存少量 range bin**，不做完整 radarCube
3. **呼吸率优先**，心跳作为后续增强
4. **只 DEBUG_TEXT 模式输出**，HOST_PROTOCOL 保持协议兼容
